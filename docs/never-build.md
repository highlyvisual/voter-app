# Never build

Features that would turn this site from information into advice. Any pull request touching these is refused at review. Referenced from CONTRIBUTING.md.

- Match percentages, "agreement" scores, or any per-candidate number a reader could read as better/worse.
- Favourites, hearts, ticks, saved shortlists, or graphs of them.
- Drag-to-rank, sort-by-anything-computed, or any ordering other than the ballot paper's.
- Endorsements, "recommended for you", "people like you chose".
- Opinion maps, ideology radars, left/right axes, party self-classification questionnaires.
- Colour intensity, badge size or placement that varies with a computed quality of a candidate or party. Party colour is identification only, at identical weight.
- Incumbency, coverage volume, poll standing or past result used as a weight in any computation shown to a voter.
- Any LLM call in a user-facing path, and any LLM call anywhere whose sources are outside the claims ledger.
- Storing anything a user entered beyond anonymous daily counts. The full postcode never leaves the lookup.
- Green/red (or any valence colour) on money figures. An increase is not "good"; a decrease is not "bad".
