# Phase 1 pull request description and dry-run results (27 September 2026)

The text below is the description for the pull request from branch `automation/phase-1`, kept here because the build session could not open the PR itself (its GitHub login cannot see the private repository). Barny opens the PR from the compare page and pastes this in.

Phase 1 of the automation plan (`docs/automation/phase-1-motion-results.md`): once a council publishes a meeting's minutes, each Full Council and Cabinet item on the council page shows what the minutes say happened, in the minutes' own words, with a link. Fixed forms of words only; **no AI is called anywhere in this PR.**

## What's in it
- **Migration** `scripts/sql/migrations/2026-09-27-council-item-outcomes.sql`: `council_item_outcomes` and `outcome_queue`, public-read RLS. **Not applied**; Barny applies it. The reader's dry run treats the missing tables as empty until then.
- **Reader** `scripts/auto/motion_outcomes.py` (uses `common.py`, dry run without the service key). For past meetings whose minutes are published it reads each item's own minute text from the Modern.gov web service (`minutesnonemptyhtmlbody` in `GetMeeting`), which the brief did not anticipate: it gives every item its own passage with no cutting. Where a council publishes only the PDF, the printed minutes are read with pdftotext and cut at the minute numbers. The link is the council's own "Printed minutes" PDF from the meeting page. Keeps the per-council behaviour of the meetings reader (browser UA for Leeds, long timeouts for slow hosts; Wiltshire added to the slow set).
- **Set-words pass** (`SET_WORDS`, commented in the file): RESOLVED / Resolved: / AGREED / "Decision: That Cabinet…" → agreed; "the motion was CARRIED" → carried; "the motion FELL" / "was LOST" → lost; withdrawn; deferred; "The report was noted" → noted. Capitals are deliberate where minutes print the verdict in capitals, so "carried out" and "Cllr X noted that" in discussion do not count. Paragraphs about an amendment, an alteration or a procedural motion are left out first, and numbered points inside a resolution are not read as verdicts of their own. An item is settled only when **exactly one** outcome is found; two different ones, or none, go to `outcome_queue` with the passage and the reason.
- **Recorded votes**: read only when the passage has exactly one recorded vote, or exactly one labelled as the vote on the motion itself beside amendment votes ("Votes for the motion (86)" next to "Votes for the amendment (23)"). Never a choice between two.
- **`--verify`**: publishes an answered queue row only if the answered sentence is in the passage word for word (whitespace and quotes normalised) and the outcome is in the fixed list; otherwise marks it rejected. Nothing fills the queue yet (phase 1b).
- **Ledger**: every published result is a `change_log` row (claim_id null, actor "motion outcomes job").
- **Workflow** `.github/workflows/motion-outcomes.yml`: Mondays 06:20 UTC after the council meetings job, manual dispatch, and on push of the reader; runs `--verify` then the read. Job added to `/status` and `weekly_review.py`.
- **Council page**: under each past item, "**Result: carried**, 16 July 2026 (86 for, 0 against, 0 abstained). “…sentence…” Minutes"; or "Minutes not yet published"; or "Minutes published; result not yet read" (open queue row); or "We couldn't read the result from the minutes" (rejected). Same wording for every council.
- `docs/data-freshness.md` and `CHANGELOG.md` updated.

## Dry run (no service key), three councils with published minutes

South Kesteven, North West Leicestershire and Wiltshire (the three that answer this machine quickly; the hosted `*.moderngov.co.uk` sites return 403 from here, as they did for the meetings reader). 129 items settled by the fixed words, 14 queued: north-west-leicestershire: 43 settled, 2 queued; south-kesteven: 44 settled, 8 queued; wiltshire: 42 settled, 4 queued. Outcomes: agreed 117, noted 9, carried 2, lost 1.

Every queued item was read by hand and belongs there: a motion 'not heard' in the proposer's absence, an item 'withdrawn from the agenda' whose minute then records a resolution, announcements and updates with no decision, and a couple of Cabinet decisions written in forms not on the list ('Cabinet approved the adoption…'). The list can grow; nothing is guessed.
